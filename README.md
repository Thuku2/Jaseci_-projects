Science Quiz Tutor 
A simple Jac language program that demonstrates a console based multiple choice science quiz.
This project is designed for grading and evaluation in educational or competition settings.

Features
•	Runs a 4-question science quiz.
•	Tracks score and percentage.
•	Provides feedback for correct/incorrect answers.
•	Includes an explanation for one incorrect answer (Gravity).
•	Assigns a letter grade (A, B, C) based on performance.
File
•	scitutor.jac → main Jac program.

Run Instructions
1.	Ensure you have Jac installed. 
2.	pip install jac-lang
3.	Run the quiz program: 
4.	jac run scitutor.jac
